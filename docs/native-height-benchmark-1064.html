Native displacement height decode · BoxLab .1064

This isolated test reads a NOM’s explicit displacement image, or a grayscale PNG. No UV unwrap is needed. It does not modify the open BoxLab project, source image or material.

The bundled 2 × 2 sample checks precision only. Choose your own NOM or height PNG for a useful device timing measurement.

Ready. Start with the sample, then choose a NOM or height PNG.

Supported: non-interlaced 8/16-bit grayscale PNG, up to 2048 × 2048 and 8 MiB encoded. RGB, alpha, palette, interlace and animation are refused explicitly. Samples retain their integer precision and source row order; no colour conversion, midpoint or strength is applied.

Three measured decodes, yielding a frame between runs. Stop after a decode exceeds 1.2 seconds; this is checked after the decode, not a hard interruption. “Decode budget passed” covers this stage only. Reported array bytes exclude browser/decompressor overhead and are not total memory. No geometry, projection, GPU upload, viewport or shadow timing is measured.
