# Radial visual selection sheets v1

25 October 2026. All 65 audited tool meanings have three original editable SVG
candidates: 195 icons, arranged on ten selection sheets. Reference format is an
icon with a small visible title underneath. These are concepts for user review;
no user choices have been accepted and no app icons have been installed.

Delivered artifacts:
- BoxLab-Icon-Selection.pdf: complete ten-page selection review.
- BoxLab-Icon-Review.html: self-contained selector, optional local persistence,
  copy/download choices. Tap the same candidate to clear it.
- BoxLab-Icon-Review-Pack.zip: PDF, HTML, ten PNG pages, overview, all 195 SVGs,
  candidates.json, audit brief and Python rebuild source.

Review by tool name and A/B/C, e.g. Extrude B, Inset A. None/alternative requests
are welcome. Shared tools reuse one choice; Join (Vertex) and Join (Object) differ.
First eight tools: Extrude, Inset, Bevel, Knife, Bridge, Sweep, Duplicate, Delete.
Colours/proportions remain provisional until the selected concepts are refined.

Validation: 65 rows, 195 unique valid SVGs, 10 pages and all tool labels present;
PDF text bounds checked; all pages rendered and visually reviewed. Selector logic
checks no defaults, single-choice replacement/toggle, 65 choices, copy and export.
No native iPad/browser rendering execution claimed. PDF is the reliable review route
if iPad Files previews do not execute HTML. SVG outlines explicitly close paths;
invalid stroke-width arguments were corrected before final validation/delivery.

Current app .967 unchanged and protected. No new hands-on app tests today.
Next: collect choices; refine selected family, then install one radial per narrow
build with routing, readability, gesture and history checks. Avoid textContent
routing pitfalls identified in the audit. No automatic whole-app icon replacement.
