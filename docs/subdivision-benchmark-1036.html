This page profiles BoxLab’s existing Catmull–Clark subdivision owner on regular quad grids. Reports split cloning, edge construction, face/edge/vertex points, adjacency and output assembly. It does not touch your open project.

Bound: 16, 64 and 256 source faces; subdivision levels 1–3; at most 16,384 generated faces (about 16,641 vertices). Each case gets two warm-ups and five timed runs. If one run exceeds 1.2 seconds, larger cases stop.

This measures mesh creation only. It does not include UV interpolation, displacement image decode/sampling, GPU upload/rendering, actual device memory, or frame-time impact. A quick timing result cannot qualify displacement preview by itself.
