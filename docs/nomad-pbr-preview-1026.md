  failed auxiliary cannot remove accepted colour. Source disposal stops later starts
  and closes late results, all textures, canvases/bitmaps and reflection references.

  PMREM per renderer, shared/refcounted, owned only by the material. Explicit scene

  No global ambient, scene environment or Studio light change.

  <=1024 square; each scalar <=512 square. Unique encoded colour+auxiliary choices
  <=8 MiB per surface, deterministic normal/roughness/metalness order. Existing raw

- Opacity, emissive and displacement stay retained-only. Full native PBR appearance,
  local/triplanar fidelity and native GPU/iPad acceptance are not inferred.
