Displacement preview feasibility · BoxLab .1041

This isolated gate does not modify the open BoxLab project. It uses BoxLab’s existing corner-UV subdivision, decodes generated grayscale PNG height maps, expands UV corners, and renders a Three.js displacement-map scene.

Bounded cases: 16, 64 and 256 source faces; levels 2, 2 and 3; 256², 1024² and 2048² generated maps. The largest geometry is capped at 16,384 faces / 65,536 corners. Each CPU stage stops if one run exceeds 1.2 seconds.

The report includes decode time, known typed-array/source byte estimates, render-command submission and animation-frame intervals. GPU timer queries are reported only when the browser exposes them. This is a feasibility comparison, not BoxLab viewport frame-time, total memory or device-GPU proof. No displacement feature ships in .1041.
